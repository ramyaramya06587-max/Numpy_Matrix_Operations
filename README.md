# NumPy Matrix Operations

## Description
This project demonstrates basic matrix operations using Python and NumPy.

## Objective
To understand matrix addition, subtraction, element-wise multiplication, matrix multiplication, and transpose operations.

## Tools Used
- Python
- NumPy
- Jupyter Notebook

## Operations Performed
1. Matrix Addition
2. Matrix Subtraction
3. Element-wise Multiplication
4. Matrix Multiplication
5. Matrix Transpose

## How to Run
1. Install NumPy:
   pip install numpy
2. Open Jupyter Notebook.
3. Copy and run the Python code.

## Output
The program displays both matrices and the results of all five operations.

## Conclusion
This project demonstrates how NumPy simplifies matrix operations and supports mathematical computations used in machine learning.
